# Context Compiler

🚧 **Note: This project is currently a Work In Progress (WIP).** 🚧

Context Compiler is an intelligent context-retrieval engine for AI coding agents. Instead of dumping entire files or relying on simple embedding-based Retrieval-Augmented Generation (RAG), this project builds an explicit **Code Graph** of your repository (tracking imports, function calls, class hierarchies, and test coverage) to figure out exactly what code an AI agent actually needs to see to solve a task.

## What It Does
When an AI agent is given a coding task, it needs context from the repository. The Context Compiler:
1. **Parses the repository** to build a rich semantic graph of all Python symbols and their relationships (using `jedi` for precise call resolution).
2. **Retrieves seed nodes** based on lexical overlaps with the task description.
3. **Expands the context** by walking the code graph, evaluating which dependencies (imports, calls, inherited classes) are most critical.
4. **Optimizes a token budget** to produce a clean, chunked "Context Bundle" containing exactly the snippets the agent needs—no more, no less.

## Getting Started

### Prerequisites
- Python 3.10+
- The dependencies listed in `requirements.txt`

### Installation
Clone the repository and install the required dependencies:
```bash
git clone https://github.com/pr0x7/context-compiler-.git
cd context-compiler-
pip install -r requirements.txt
```

### Basic Usage
Currently, the easiest way to test the compiler is via the `minimal_agent.py` script. This script takes a target repository and a task description, compiles the optimal context, and simulates an agent interacting with it.

```bash
# Set PYTHONPATH so the modules can find each other
export PYTHONPATH=.

# Run the minimal agent simulator against the current repository
python3 context_compiler/ledger/minimal_agent.py . "understand and modify run_ablation"
```

You can also run the internal test suite to verify everything is working correctly:
```bash
python3 -m pytest -v tests/
```
